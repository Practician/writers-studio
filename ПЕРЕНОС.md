# Writer's Studio — запуск на другом ПК

Это чистая копия исходников с полной историей git (папка `.git` внутри).

## Что нужно на новом ПК

1. **Node.js** версии 20 или новее — https://nodejs.org

## Первый запуск

```bash
cd writers-studio-src
npm install
```

2. Создайте файл `.env` в корне проекта (по образцу `.env.example`) и впишите свой ключ:

```
GEMINI_API_KEY=ваш_ключ_из_Google_AI_Studio
```

Ключ бесплатно выдаётся на https://aistudio.google.com/apikey
(файл `.env` со старого ПК сюда сознательно не скопирован — секреты переносите отдельно).

Можно добавить резервные ключи — при исчерпании дневной квоты первого сервер
переключится на следующий автоматически:

```
GEMINI_API_KEY_2=резервный_ключ
GEMINI_API_KEY_3=ещё_один
```

Важно: резервные ключи должны быть из **разных проектов** Google AI Studio —
квота считается на проект, два ключа одного проекта делят одну общую квоту.

3. Запуск в режиме разработки:

```bash
npm run dev
```

Приложение откроется на http://localhost:3000

## Продакшен-сборка (по желанию)

```bash
npm run build          # соберёт клиент и сервер в dist/
set NODE_ENV=production && npm start   # Windows
```

## Полезные команды

- `npm test` — тесты (26 шт.)
- `npm run lint` — проверка типов
- `npx tsx scripts/ai-tell-score.ts файл.txt` — локальная оценка текста на генеративные признаки
- `npx tsx scripts/check-detector-reports.ts отчёт.json` — проверка отчётов Яндекс-нейродетектора

## Примечание про имя папки

Оригинальная папка называлась `writer's-studio` — апостроф в пути ломал часть
node-инструментов. Эта копия названа `writers-studio-src`; сохраняйте имя без
апострофов, кириллица в родительском пути допустима.
