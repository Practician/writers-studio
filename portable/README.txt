Writers Studio — portable PC package

Требования: Node.js 20 или новее.

Linux/macOS:
1. Откройте терминал в этой папке.
2. Выполните ./START-Writers-Studio.sh
3. Откройте http://localhost:3000

Windows:
1. Установите Node.js 20 или новее.
2. Запустите START-Writers-Studio.cmd.
3. Откройте http://localhost:3000

API-ключи не включены в архив. Если нужны AI-функции, создайте локальный файл .env по образцу .env.example. Не публикуйте этот файл.

Данные проекта и журнал браузера хранятся локально в браузере. Для остановки сервера нажмите Ctrl+C в окне терминала.
