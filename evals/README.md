# Writers Studio Evals

Этот каталог фиксирует **контракты качества**, а не измеряет авторство и не пытается оптимизировать рукопись под внешние детекторы. Набор должен запускаться до изменения prompts, моделей, правил контекста или retrieval.

## Запуск

```bash
npm run evals
```

По умолчанию используется `mockProvider.mjs`: он читает заранее заданный `mockOutput` из fixture и не отправляет текст во внешний сервис. Поэтому contract regressions воспроизводимы и безопасны для рукописи.

## Какие инварианты покрываются

Текущие fixtures проверяют сохранение защищённых терминов, отсутствие скрытого применения, выдержку POV и соблюдение явного правила автора. При добавлении новой возможности нужно добавить fixture с целью, безопасным минимальным входом, ожидаемым инвариантом и причиной появления теста.

Живые LLM-evals допускаются только отдельной opt-in конфигурацией, с обезличенными фрагментами и без ключей в YAML-файлах. Результат живой модели является review-сигналом, а не автоматически принимаемым решением.
