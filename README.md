# Writer's Studio 🖋️

Writer's Studio — это мощный инструмент для писателей, объединяющий возможности искусственного интеллекта и удобный интерфейс для создания, редактирования и стилизации литературных произведений. Проект специально настроен для работы над книгами (включая проект «Лабиринт»), обеспечивая глубокую интеграцию контекста сюжета, персонажей и авторского стиля.

## 🌟 Основные возможности

* **Умная генерация текста**: Автоматическое написание и продолжение глав с учетом заданного канона, лора и предыдущих событий.
* **Адаптация авторского стиля (Humanization)**: Умные алгоритмы, которые помогают избавить сгенерированный текст от "машинного" стиля, делая его более живым, ритмичным и похожим на человеческую прозу.
* **Управление лором и персонажами**: Встроенные инструменты для структурирования информации о мире и героях.
* **Интерактивный редактор**: Удобная работа с черновиками, версиями текстов и внесение правок в режиме реального времени.
* **Импорт и экспорт (DOCX)**: Поддержка работы с форматом Microsoft Word для удобного обмена главами.
* **Глубокий анализ текста**: Оценка стилистики, ритмики, частоты повторений и соответствия "живому" тексту.

## 🚀 Как запустить проект локально

**Требования:** Установленный [Node.js](https://nodejs.org/).

1. **Установите зависимости:**
   ```bash
   npm install
   ```

2. **Настройте переменные окружения:**
   Создайте файл `.env` (или используйте `.env.local`) и укажите ваш API ключ Gemini:
   ```env
   GEMINI_API_KEY=ваш_секретный_ключ
   ```

3. **Запустите сервер разработки (Frontend + Backend):**
   ```bash
   npm run dev
   ```
   Приложение запустится локально и будет доступно в браузере (порт будет указан в консоли).

## 🛠 Технологический стек
* **Frontend:** React 19, Tailwind CSS, Vite, Markdown.
* **Backend:** Node.js, Express, TSX.
* **AI:** Google GenAI (Gemini).
* **Работа с документами:** `docx`, `mammoth`.
